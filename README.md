# 衡契｜天河中小企业合同风险助手

“溯往启新·智惠天河”2026年青AI天河人工智能协作创新大赛参赛版本。项目属于“AI应用创新·数智天河”板块的“商业服务”方向。

核心链路：

```text
上传DOCX/PDF/TXT或粘贴文本 -> 提取带位置合同块 -> 本地规则审查 -> 人工核验法律依据 -> 可选DeepSeek V4补充 -> 风险提示
```

## 当前状态

- 页面右上角提供“连接AI”，可直接选择SiliconFlow或DeepSeek、填写密钥并测试连接，不需要修改源码。
- 默认可将API密钥通过Windows账户级加密安全记住，重启衡契后自动恢复连接；也可选择仅本次运行。
- 未连接AI时，页面会明确显示“本地规则演示”，不会冒充AI输出。
- 配置DeepSeek密钥后，使用`deepseek-v4-pro`补充跨条款风险，并对引用原文进行后端验证。
- 使用SiliconFlow时，网页默认填入`deepseek-ai/DeepSeek-V4-Flash`；默认关闭思考模式以控制响应时间和费用。
- AI结果采用逐项结构校验：常见字段别名和中英文风险等级会自动归一；单条异常不会拖垮整份报告；JSON截断或格式异常时会自动进行一次精简重试。
- 所有AI原文引用仍必须能在真实合同文本块中逐字核对，否则该风险会被忽略。
- 风险会区分“合规风险、效力风险、约定缺失、商业风险”，避免把不利条款直接说成违法或无效。
- 本地规则只能引用`backend/data/legal_bases.json`中的人工核验依据；AI输出不能自行添加法条。
- AI输出中的未经核验法条、处罚金额、营业额比例及确定违法结论会被后端拦截并改为中性提示。
- 本地规则与AI按语义领域去重，并按现金流、数据合规、核心知识产权、解除等经营优先级排序。
- 报告可展开查看条文摘要、适用说明、适用边界、官方来源和人工核验日期。
- 支持DOCX、文本型PDF、TXT及粘贴文本。
- 支持风险等级、领域、发现方式筛选及关键词搜索。
- 支持一键复制修改建议和谈判话术、导出可直接办公使用的 Word（DOCX）审查报告。
- 支持近期审查记录，结构化结果默认保留24小时，合同全文不入库。
- 桌面端和移动端均使用响应式布局。
- 审查完成后进入独立三栏工作台，风险列表、合同原文和处理建议可以联动查看。
- 当前上传会话支持按风险定位并高亮原文；历史记录只保留证据摘录，不保存合同全文。
- 支持将单项风险标记为已采用、已沟通或暂时忽略，并实时显示整体处置进度。
- 当前不支持扫描PDF、旧版DOC和在线修订。

## 本地运行

### 一键启动（Windows）

运行要求：Windows 10/11、Python 3.11或更高版本。首次运行需要联网安装Python依赖，之后可以离线启动。

双击项目根目录的：

```text
双击启动衡契.cmd
```

启动器会自动创建项目专用Python环境、安装锁定版本的依赖并打开浏览器。然后访问：

```text
http://127.0.0.1:8765
```

使用期间请保持启动窗口开启；关闭窗口即可停止服务，也可以双击`stop-local.cmd`。启动器只监听`127.0.0.1`，不会向局域网或公网开放端口。

启动后可在网页右上角点击“连接AI”，选择SiliconFlow或DeepSeek并填写自己的API密钥。未连接AI时仍可使用本地规则演示模式。密钥不会随作品源代码分发。

### 从零安装

后端：

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:AI_API_KEY="你的DeepSeek密钥"  # 可选；也可以启动后在网页中连接
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

前端：

```powershell
cd frontend
npm install
npm run dev
```

开发模式访问`http://127.0.0.1:5173`。

生产构建后，FastAPI会直接提供`frontend/dist`中的静态文件。参赛提交包已经包含生产构建，因此评委运行作品不需要安装Node.js。

网页首页提供“一键体验示例”，可以直接使用项目自带的原创技术服务合同完成完整审查流程。

## 自动测试

```powershell
cd backend
python -m unittest discover -s tests -v
```

测试覆盖文本、DOCX、PDF解析，核心风险规则，法律依据白名单、AI虚构依据拦截、SiliconFlow请求参数、Word报告导出、近期审查接口及完整API流程。

当前本地规则覆盖付款暂停、验收机制、服务范围扩张、需求变更、知识产权边界、数据使用、无限责任、单方解除、诉讼与仲裁冲突及争议解决地。每项规则要么绑定人工核验依据，要么明确标记为无直接法条的商业风险。当前依据库不是完整法律数据库，维护规范和来源清单见[LEGAL_SOURCES.md](LEGAL_SOURCES.md)。

## 数据处理

- 文件在内存中解析，不写入公开静态目录。
- SQLite只保存结构化结果，不保存合同全文。
- 结果默认保留24小时。
- 从网页连接时，可选择仅保存在服务内存，或使用Windows DPAPI按当前账户加密保存到Git忽略的`.runtime`目录；不会写入源码、浏览器存储或数据库。
- 点击“清除连接和密钥”会同时断开当前连接并删除本机加密文件。
- AI配置接口仅允许从本机访问，供应商接口地址使用内置白名单。
- 本地部署可从`.env.local`读取密钥，该文件不会提交到Git。
